## Introducción (impacto)
Soy Data Analyst; este repositorio contiene un tablero de Power BI construido para analizar finanzas personales mediante un modelado en estrella y medidas DAX. El objetivo principal es transformar datos financieros en insights accionables: identificar tendencias de gasto, medir ahorro, y priorizar decisiones financieras. Estas visualizaciones están pensadas para compartir en LinkedIn como ejemplo de trabajo profesional en BI y análisis de datos.

> Insight clave: un buen tablero combina modelado consistente (modelo estrella), medidas DAX robustas y storytelling visual para que las decisiones se tomen en minutos, no horas.

## Qué muestra el tablero — Resumen para reclutadores
- Seguimiento de ingresos y gastos por categoría y periodo
- Medidas principales (ejemplos implementados): Total Ingresos, Total Gastos, Ahorro Neto, Tasa de Ahorro (%), Variación mensual, Acumulado YTD
- Time intelligence: comparaciones mes a mes y año contra año
- Filtros interactivos: fecha, categorías, subcategorías y vistas por periodo
- Visualizaciones pensadas para storytelling: KPI cards, series temporales, barras apiladas y tablas resumen


## Estructura técnica
- Modelo: Estrella (tablas de hechos y dimensiones)
- Medidas: DAX centradas en agregaciones, porcentajes y cálculos acumulados (YTD)
- Exportes: PDF del informe para compartir o archivar (Global.pdf, september.pdf)
